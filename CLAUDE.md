## Gotchas
- Cloudflare (owner's account, no connector): SSL/TLS = Full, the 4 apex A records are Proxied (2026-10-22); `www` CNAME and the Resend records (send, rsend, resend._domainkey, _dmarc) stay DNS only. GitHub Pages may show DNS warnings because of the proxy — expected.
- Emails send from `noreply@buyrblx.com` via Resend: they only work once buyrblx.com is bought and verified in Resend.
- Supabase Auth → URL Configuration has `https://buyrblx.com/**` and `https://www.buyrblx.com/**` (owner added 2026-10-22).
- Promo code `BUYRBLX` was renamed from `BUYLANCE`; redemption checks look for both.
- DB → email edge functions authenticate with an `x-email-secret` header from `private.email_hook_headers()` (vault secret `email_hook_secret`); the functions run with verify_jwt off and check it via `check_email_hook_secret`.
- Table grants were stripped at some point (new tables don't get default grants — even `service_role` needs an explicit `grant ... to service_role` for edge functions to use them); grant only what the site uses. Buyers may update only `profiles(roblox_username, roblox_avatar_url, roblox_id, vip_cancelled)` and `orders(discord_thread_id, last_buyer_activity_at)`. `guard_order_insert` keeps browser-created orders from starting as delivered/completed.
- Discord goes through the `discord-notify` edge function (events: new_order, order_chat, order_remind, order_confirmed, order_disputed, message_report, new_ticket, ticket_urgent). Webhook URLs are secrets DISCORD_ORDERS_WEBHOOK (orders forum: one thread per order, incl. reports) and DISCORD_TICKETS_WEBHOOK (support forum, incl. urgent flags); the owner's Discord ID (for @mentions) is in the function. Never put webhook URLs back in the pages.
- Admin order list: completed orders move from "This week" to "History" after 7 days. Order numbers are never renumbered.
- Cart + checkout live in one shared file for all 12 shop pages: `cart.js` + `cart.css` (drawer and checkout popup markup are injected by cart.js; pages only keep header buttons calling `toggleCart()` / `addToCart(...)`). All money math is `computeCartTotals()`. Tip step is tip.js.
- Processing fee (`calculateProcessingFee` in cart.js): $0.50→$1.50 curve for small orders, then 4.5% + $0.30 once that's higher (≈$27+), so PayPal's fee is covered (owner's call 2026-10-23).
- Discord cleanup: edge function `discord-cleanup` (cron job `archive-completed-order-threads`, hourly at :07, x-email-secret) **deletes** forum threads 7 days after done — completed/cancelled orders, closed tickets, `feedback_reports` posts. Needs secret DISCORD_BOT_TOKEN (a bot with Manage Threads in the server); without it the job just skips. Old `swift-action` cron (`archive-completed-order-threads-hourly`) was unscheduled 2026-10-25.
- "Found something off?" / "Can't find an item?" cards and the search "no results" box open a popup (`openFeedback` in cart.js) → `submit_feedback()` → `feedback_reports` → discord-notify `feedback` → new post in the #reports forum (secret DISCORD_REPORTS_WEBHOOK, owner added 2026-10-24; falls back to the tickets forum if unset).
- VIP subscribe / renew / cancel are posted by paypal-vip into one orders-forum thread "👑 VIP subscriptions" (thread id in `app_settings.vip_discord_thread`). VIP marketing text doesn't name the prizes (owner's call); the wheel page shows prizes + odds.
- Trustpilot: domain verified (meta tag in index.html head — keep it). Public page https://www.trustpilot.com/review/buyrblx.com; review button (`/evaluate/buyrblx.com`) on every completed order in order.html + link in the homepage trust pill. Trustpilot rules: no rewards for reviews, ask every buyer. **Auto-invites (AFS):** trigger `on_order_completed_email` → `email_order_completed()` emails the buyer a thank-you when an order becomes completed (skips vip_spin / $0) and BCCs `app_settings.trustpilot_afs_email`; send-notification-email adds Trustpilot's `application/json+trustpilot` block (name = Roblox username, reference = order number). Only works while Resend can send from buyrblx.com.
- Site text never says where the owner is from (owner's call 2026-10-24 — the old "Filipino-run" line showed up in Google; terms no longer name a country's law, no DTI/SEC placeholder, no PHP currency). The "More About BuyRBLX" block is identical on all 12 shop pages. index.html has WebSite/Organization JSON-LD so Google shows the name "BuyRBLX".
- Homepage "How It Works" (`#how-it-works`, `.hiw-*` styles in index.html) sits between the shop and the perks: 3 steps + "5–15 minutes" pill.
- Homepage "N+ orders delivered" counter: `get_public_order_count()` (delivered + completed, excludes vip_spin); hidden until the count reaches `app_settings.order_counter_min_show` (50).
- Cashback (`award_cashback()` trigger on completed orders): 3% of the order total, 5% if the buyer's VIP is active at completion (owner's call 2026-10-24). Site text says "3% (5% for VIP)" everywhere — wallet dropdown, perk card, cashback popup, checkout trust row, VIP popup/banner, bot, meta descriptions.
- Discounts: one per order — typed code (BUYRBLX / personal), personal reward code (loyalty, win-back), or **daily 5%** (`get_daily_discount()`: unlocks once completed orders total $10, then orders of $2+, comes back 24h after use).
